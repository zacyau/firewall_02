## 二、数据存储架构

项目采用**配置文件 + 数据库**双存储架构，职责分明：

| 存储方式 | 文件/位置 | 存储内容 | 读写方 |
|---------|----------|---------|-------|
| **配置文件** | `config/devices.py` | 防火墙设备信息（名称、厂商、IP、区域拓扑） | `ConfigManager` 读写，`PathCalculator`/`PolicyManager`/`GroupManager`/`PolicyValidator` 读取 |
| **SQLite 数据库** | `database/firewall_platform.db` | 地址组、端口组、安全策略、策略审计日志、组配置状态 | `GroupManager`、`PolicyManager`、`PolicyValidator` 读写 |

### 配置文件数据结构 (`firewall_devices`)

```python
firewall_devices = {
    'USG6660': {
        'name': 'USG6660',
        'vendor': 'huawei',
        'ip': '172.31.255.2',
        'zones': {
            'edge': {                          # 末端区域（直连网段）
                'Core_Server': ['172.25.1.0/24', '172.25.2.0/24'],
                'PC': ['172.27.1.0/24'],
            },
            'forward-in': {                    # 入方向转发区域
                'untrust': { 'net': ['0.0.0.0/0'], 'dev': [] },
            },
            'forward-out': { ... },            # 出方向转发区域
            'mixed': { ... },                  # 混合区域
        },
    },
}
```

### 数据库表结构

| 表名 | 用途 |
|-----|------|
| `firewall_devices` | 设备注册信息（仅状态/心跳，区域配置已迁移到配置文件） |
| `security_policies` | 生成的安全策略记录 |
| `policy_audit_logs` | 策略操作审计日志 |
| `address_groups` | 地址组定义 |
| `port_groups` | 端口组定义 |
| `address_group_device_status` | 地址组在各防火墙上的配置状态 |
| `port_group_device_status` | 端口组在各防火墙上的配置状态 |

#### 策略生成 API（核心流程）

```
POST /api/v1/policies/generate
  │
  ├── policy_manager.generate_policy(policy_config)
  │   │
  │   ├── [有地址组] → _get_address_groups_from_db()      # 从数据库读取地址组
  │   │                _get_port_groups_from_db()          # 从数据库读取端口组
  │   │                generate_policy_with_groups()       # 基于组的策略生成
  │   │                  │
  │   │                  ├── path_calculator.expand_ip_ranges(source_ips)     # 展开IP列表
  │   │                  ├── path_calculator.calculate_paths_for_ip_pairs()   # 批量路径计算
  │   │                  │     └── calculate_path(src_ip, dst_ip)             # 单条路径计算
  │   │                  │           ├── _find_network_in_direct_map()        # 查找直连网络
  │   │                  │           ├── _find_middle_firewalls()             # 查找中间防火墙
  │   │                  │           ├── _complete_src_zone()                 # 补全源区域
  │   │                  │           └── _complete_dst_zone()                 # 补全目的区域
  │   │                  │
  │   │                  ├── path_calculator.merge_paths_by_consistency()     # 合并相同路径
  │   │                  │
  │   │                  └── [对每条路径的每个防火墙]
  │   │                        ├── path_calculator.get_policy_config()        # 获取策略配置
  │   │                        ├── FirewallFactory.create_firewall()          # 创建适配器
  │   │                        └── adapter.create_security_policy()           # 生成CLI脚本
  │   │                              └── _render_template("xxx_policy.j2")    # Jinja2模板渲染
  │   │
  │   └── [无地址组] → 直接调用 calculate_path() + 生成策略
  │
  └── [dry_run=true] → policy_validator.validate_generated_policies(result)
```

#### 策略应用 API

```

        │
        ├── [simulate=true]  → 保存策略到数据库，状态=applied
```

### 3.4 路径计算引擎核心流程

```
PathCalculator.__init__(devices_config)
  ├── _build_direct_network_map()     # 构建 {网段 → {防火墙, 区域}} 映射
  │     遍历所有设备的 edge 区域，提取直连网段
  │
  ├── _build_middle_forward_map()     # 构建 {防火墙 → {对端防火墙: [中间防火墙]}} 映射
  │     遍历所有设备的 forward-in/forward-out/mixed 区域
  │     根据 dev 列表推导防火墙间转发关系
  │
  └── _build_internet_forward_map()   # 构建 {防火墙 → {默认出接口区域}} 映射
        遍历 forward-out/mixed 区域，提取默认出口

PathCalculator.calculate_path(src_ip, dst_ip)
  │
  ├── Step 1: _find_network_in_direct_map(src_ip)  → src_fw, src_zone
  ├── Step 2: _find_network_in_direct_map(dst_ip)  → dst_fw, dst_zone
  │
  ├── Step 3: [src_fw == dst_fw]  → 同一防火墙，直接返回
  │
  ├── Step 4: _find_middle_firewalls(src_fw, dst_fw)  → 中间防火墙列表
  │     ├── 查 middle_forward_map
  │     └── 递归查找路径（深度限制10跳）
  │
  ├── Step 5: _complete_src_zone()  → 补全源防火墙的出方向区域
  ├── Step 6: _complete_dst_zone()  → 补全目的防火墙的入方向区域
  │
  └── Step 7: 组装完整路径 [{firewall, src_zone, dst_zone}, ...]
```

## 六、适配器模式

### 6.1 工厂模式

```
FirewallFactory.create_firewall(device_config)
  │
  ├── vendor="huawei"    → HuaweiFirewallAdapter(device_config)
  ├── vendor="hillstone" → HillstoneFirewallAdapter(device_config)
  ├── vendor="h3c"       → H3CFirewallAdapter(device_config)
  └── vendor="juniper"   → JuniperFirewallAdapter(device_config)
```

### 6.2 适配器统一接口

| 方法 | 功能 | 使用场景 |
|-----|------|---------|
| `connect()` | SSH连接设备 | 真实模式下策略下发 |
| `disconnect()` | 断开SSH连接 | 真实模式下策略下发 |
| `check_heartbeat()` | 检查设备在线状态 | 设备心跳检测 |
| `create_security_policy()` | 生成策略CLI脚本 | 策略生成 |
| `apply_policy()` | 下发策略到设备 | 策略应用（真实模式） |
| `get_zone_by_ip()` | 根据IP判断安全区域 | 区域判断 |
| `generate_cli_command()` | 生成CLI命令 | 策略生成 |
